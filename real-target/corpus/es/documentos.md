# Documentos que Puede Usar para Solicitar

Esta página enumera los documentos que acepta el Programa de Beneficios Comunitarios.
Todos los ejemplos son ilustrativos y sintéticos.

Para comprobar su identidad, puede usar una licencia de conducir, una tarjeta de
identificación estatal o un pasaporte. Para comprobar sus ingresos, puede usar talones
de pago recientes o una carta firmada de su empleador. Para comprobar su residencia,
puede usar una factura de servicios públicos o una copia de su contrato de alquiler.

Si no puede presentar uno de estos documentos, dígale a su trabajador social. El
programa puede aceptar pruebas alternativas. No necesita presentar un número de Seguro
Social para solicitar asistencia alimentaria de emergencia.
